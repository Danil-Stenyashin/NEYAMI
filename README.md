# NEYAMI

Свободный музыкальный сервис: загружай что хочешь, как на SoundCloud, и слушай волну, которая
понимает тебя лучше «Моей волны» и честно объясняет каждую рекомендацию.

## Чем отличается от других

| | NEYAMI |
|---|---|
| 🎯 **Автодроп** | Лучший момент трека находится сам — по тому, где люди переслушивают и куда перематывают (а не просто «что играло чаще» — начало всегда лидирует). Пока данных мало, используется энергетический пик, найденный анализом звука прямо в браузере при загрузке. Тепловая карта и метка дропа видны прямо на полосе перемотки, кнопка ⤓ переносит к дропу. |
| ⚡ **Быстрый поиск** | Треки по 15 секунд, сразу с дропа. ← не моё, → нравится, ↓ слушать целиком. Волна учится в разы быстрее, чем на полных прослушиваниях. |
| 🧭 **Прозрачный вкус** | Страница «Мой вкус» показывает всё, что волна о вас знает: любимые и нелюбимые теги, треки, которые сильнее всего повлияли. Тег можно усилить (＋), забыть (↺) или скрыть (⊘), трек — «забыть». |
| 🕶 **Не запоминать** | Режим, в котором прослушивания не влияют на вкус: когда музыку включает гость, ребёнок или вы ставите фон для вечеринки. |
| 🌉 **Волна-мост** | «От #lofi к #dnb за 8 треков»: волна плавно ведёт от одного настроения к другому. Мост идёт и по тегам, и по реальному звуку: темп и энергия меняются постепенно. Для тренировки, вечеринки, засыпания. |
| 🔊 **Волна слышит звук** | При загрузке браузер анализирует трек: темп (BPM), энергию, ударность, яркость, динамику. Волна запоминает, как звучит то, что вам нравится, и находит похожее даже у авторов, которые не ставят теги. |
| 🕐 **Волна по контексту** | Утром, днём, вечером, ночью и в выходные вкус разный, и волна это учитывает: ночью — то, что вы слушаете ночью, утром — утреннее. На странице «Мой вкус» видна сетка «время суток × будни/выходные». Можно выключить. |
| 💬 **«Почему этот трек»** | У каждой рекомендации есть объяснение: похожие теги, «те, кому понравился X, лайкают и это», подписка, свежая находка. |
| 🎚 **Ручки управления** | Ползунки «любимое ↔ новое» и «популярное ↔ андеграунд» сразу перестраивают волну. |
| 🌱 **Шанс для новичков** | Треки с малым числом прослушиваний получают бонус исследования — новые авторы попадают в рекомендации, а не тонут. |

### Свобода и модерация

Без премодерации и без скрытого занижения в выдаче. Фильтры — у слушателя: автор ставит
метку 18+, а слушатель сам решает, скрывать ли такое. Удаляется только то, что нарушает закон или
чужие права: жалоба принимается лишь по причинам `copyright`, `illegal`, `spam`, `impersonation`.
Жалобы «не нравится» не принимаются, для этого есть 👎.

## Как работает волна

Код: `src/recommender.js` (без БД, легко тестировать).

1. **Сигналы.** Дослушал (+1), лайк (+3), «не то» (−4), пропуск в первые секунды (−1.5),
   пропуск ближе к концу (−0.25), быстрый поиск (±0.5). Неявные сигналы затухают с полупериодом
   3 недели, явные оценки максимум вдвое.
2. **Профиль вкуса** по тегам и артистам, с ручными правками.
3. **Коллаборативная фильтрация** item-item по лайкам других слушателей.
4. **Качество** (байесовская дослушиваемость) и **популярность**, вес задаётся ползунком.
5. **Исследование:** свежие и малоизвестные треки получают шанс.
6. **Знакомое и новое:** любимое возвращается, если не звучало больше суток. Только что
   игравшее откладывается.
7. **Разнообразие:** один артист не играет два раза подряд.
8. **Звук:** центр «нравится» и центр «не нравится» в пространстве признаков (`src/sound.js`).
   Темп сравнивается с учётом «вдвое быстрее»: 87 и 174 BPM почти одно и то же.
9. **Контекст:** те же сигналы ещё раз, но с весом «насколько тот момент похож на сейчас»
   (гауссово ядро по часам, σ = 2.5 ч, и множитель за совпадение будни/выходные). Доля контекста
   растёт по мере накопления данных, до 50%.

Ранний пропуск или 👎 сразу перестраивают очередь, без ожидания.

Код автодропа: `src/moments.js`. Трек делится на 100 бинов. Для каждого бина считается «избыток» прослушиваний
над минимумом слева, потому что естественная кривая только убывает и любой рост означает
перемотку или повтор. К нему прибавляются точки перемотки с весом 2. Лучший момент — окно 15 с с максимальной
суммой, старт за 3 с до пика.

## Запуск

Нужен **Node.js 22.13 или новее** (подойдёт LTS с https://nodejs.org). Больше ничего ставить не нужно:
база данных встроена в Node.js, внешних зависимостей нет.

### Windows — установщик (рекомендуется)

Node.js и командная строка не нужны.

1. Скачайте **`NEYAMI-Setup.exe`**: на GitHub в разделе **Releases**, или во вкладке **Actions** →
   последняя успешная сборка «Windows-приложение» → внизу **Artifacts → NEYAMI-Setup-Windows** (это zip-архив,
   внутри установщик).
2. Запустите установщик. Он ставит NEYAMI в один клик, без прав администратора, и создаёт ярлыки на рабочем
   столе и в «Пуске». Так как у приложения пока нет платной цифровой подписи, Windows может показать синее окно
   «Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. NEYAMI откроется сам. При первом запуске создаётся демо-каталог, чтобы было что послушать.
4. Значок NEYAMI у часов (в трее): играть/пауза, следующий трек, **адрес для iPhone** (нажмите — скопируется),
   «Запускать вместе с Windows», выход. Крестик окна прячет NEYAMI в трей — музыка и доступ с iPhone продолжают работать.
5. Если Windows спросит про брандмауэр — разрешите доступ **в частных сетях**, это нужно для iPhone.

Ваши данные (база и загруженные треки) лежат в `%APPDATA%\NEYAMI\data` и сохраняются при обновлении и удалении
приложения.

Новую версию установщика можно выпустить, поставив git-тег `v…` (например, `v0.2.0`): сборка на GitHub сама
выложит его в Releases.

### Windows — без установки (для разработки)

Установите Node.js LTS с https://nodejs.org, скачайте проект (Code → Download ZIP) и дважды щёлкните
**`NEYAMI.cmd`** — запустится сервер и откроется окно NEYAMI в Edge. Окно консоли не закрывайте.

### iPhone

NEYAMI работает на компьютере, а iPhone подключается к нему по домашней Wi-Fi.

1. Запустите NEYAMI на компьютере. В окне консоли будет строка вида
   `С телефона (та же Wi-Fi сеть): http://192.168.1.5:3000`.
2. На iPhone, подключённом к той же Wi-Fi, откройте этот адрес в **Safari**.
3. Нажмите **«Поделиться» → «На экран „Домой“»**. Появится иконка NEYAMI. Приложение открывается на весь
   экран, музыкой можно управлять с экрана блокировки и из наушников.
4. В приложении с экрана «Домой» войдите заново: у него свои cookie, отдельные от Safari.

Ограничения такого подключения (по http в домашней сети): работает, только пока включён компьютер и
вы дома, и нет офлайн-кэша оболочки. Чтобы слушать откуда угодно и по https, нужен туннель или сервер.
Самый простой бесплатный туннель, без регистрации:

```bash
cloudflared tunnel --url http://localhost:3000
```

Он выдаст адрес `https://….trycloudflare.com`, который откроется на iPhone где угодно. На Windows cloudflared
ставится командой `winget install --id Cloudflare.cloudflared`. Адрес меняется при каждом запуске и
доступен всем, кто его знает, поэтому для постоянного использования лучше развернуть NEYAMI на сервере.

### macOS / Linux

```bash
./start.sh
```

### Из терминала (любая система)

```bash
npm run seed
```

```bash
npm start
```

`npm run app` — то же самое, но сразу открывает окно. Демо-аккаунты (пароль `demo1234`): `demo` с чистым
вкусом и `night_owl` с историей прослушиваний. Данные лежат в `./data` (или в `$DATA_DIR`), порт задаётся
переменной `$PORT`. Чтобы начать с чистого демо-каталога, удалите папку `data` и запустите снова.

### Тесты

```bash
npm test
```

## Структура

```
src/main.js         запуск: адреса для телефона, окно приложения (--open)
src/server.js       HTTP API, загрузка, стриминг с Range, раздача фронтенда
src/recommender.js  волна, мост, профиль вкуса
src/moments.js      автодроп по тепловой карте
src/sound.js        сравнение треков по звучанию
public/audio-features.js  анализ звука (общий для браузера, сида и тестов)
src/db.js, auth.js  схема SQLite, пароли (scrypt), сессии
public/             SPA: волна, быстрый поиск, вкус, загрузка, профили
public/sw.js, manifest.webmanifest, icons/   установка как приложения (PWA)
NEYAMI.cmd, start.sh  запуск двойным щелчком (Windows) и из терминала (macOS/Linux)
desktop/main.cjs    приложение для Windows/macOS/Linux (Electron): окно, трей, встроенный сервер
.github/workflows/windows.yml  сборка установщика и проверка на настоящей Windows
src/demo.js         демо-каталог (для `npm run seed` и первого запуска приложения)
scripts/seed.js     демо-каталог с синтезированными треками
test/               unit- и API-тесты
```
